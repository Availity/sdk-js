## GitHub Releases

You can also view [all releases on GitHub](https://github.com/Availity/sdk-js/releases) which includes tagged versions across all packages.

## Upgrade Guides

When upgrading between major versions, check the changelog for `BREAKING CHANGES` entries. Breaking changes are always listed at the end of a version entry and describe what changed, why, and how to migrate.
